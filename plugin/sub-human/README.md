# sub-human

sub-human lets several people each work in their own Claude Code session while what each session learns, decides and
changes reaches the others, and their Claudes, as it happens. Nobody stops to write a status update or copy between
chats.

This is v2, a rebuild from the 0.8 proof of concept. It is **in progress** and not yet usable.

The design: `docs/PRD.md`, `docs/ARCHITECTURE.md` and `docs/TESTING.md` in the repository.
